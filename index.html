01网络安全是什么CYBERSECURITY
网络安全，说白了就一件事：保护电脑、服务器、网站和数据，不被坏人偷走、改掉或者弄坏。
刚入门、一个术语都没听过？没关系，这一节就把这些词翻译成人话。整个领域的核心目标叫 CIA 三要素，用生活里的例子一看就懂：
Confidentiality

机密性

就像银行卡密码，只能你自己知道，被旁人瞄到就麻烦了。

Integrity

完整性

就像转账金额：你转 100 块，账单不能悄悄变成 1000 块。

Availability

可用性

就像ATM 得能取钱：网站被打到打不开，就是可用性出了问题。

一句话记住：不让看（机密）、不让改（完整）、不让停（可用）。几乎所有安全技术，都围着这三件事转。

02CTF 竞赛简介CAPTURE THE FLAG
CTF，全称 Capture The Flag【夺旗赛】，是网络安全领域最常见的竞赛形式。可以把它理解为网络安全版的闯关解谜游戏。主办方把一串特殊字符（flag）藏在题目或服务器里，找到并提交就能得分。

解题模式 · Jeopardy

  • 像做一张卷子，题目按方向和难度分类
  • 各做各的，不用管别人
  • 最适合新手入门

攻防模式 · AWD

  • 多支队伍互打，同时守住自己的机器
  • 节奏快、压力大，像真实对抗
  • 下一节详细讲

混合模式

  • 同一场比赛里，两种玩法都有
  • 综合能力、体力分配都得有
  • 大型赛事常见

常见方向

  • Web、Pwn、Reverse、Crypto、Misc
  • 新手建议从 Web 或 Misc 入手
  • 慢慢摸索，找到自己感兴趣的方向
新手须知：不用一上来就追求高难度题目。先了解比赛形式，知道得分规则，把基础打牢，后续再逐步深入。

03AWD 攻防对抗ATTACK WITH DEFENSE
AWD，全称 Attack With Defense【攻防对抗】，是 CTF 中最接近真实战场的玩法。每支队伍分到相同的靶机，既要攻击别人拿分，又要防守自己的机器，一边打别人、一边守自己。
想象成：每支队伍分到一间「房子」，里面有几台服务器。 你既要撬开别人家的门拿东西，又要看好自己家的门。 打别人得分，被人打扣分，就这么简单。
基本规则
  • 每支队伍分到一台或多台一模一样的靶机 「靶机」就是专门用来练习和比赛的服务器，不是真实业务系统
  • 比赛开始后要同时做两件事：攻击别人拿 flag 得分，守住自己的机器不让 flag 被拿走
  • 主办方有 Check 机制，会定期检查你的服务是否存活 服务挂了会扣分，所以「别把机器搞崩」和「拿分」同样重要
  • 主办方还会定时刷新 flag，防止有人躺赢 上一轮的旗子这轮就作废，必须持续攻防
新手建议：第一次听说 AWD 会觉得难，这是正常的。先把解题 CTF 打熟，再学 Linux、日志和流量分析。等这些基础扎实了，AWD 自然就能上手。

04给新手的五条建议TIPS
1 先打地基，再谈攻防。计算机网络、Linux、Python、Web 基础绕不开。看着慢，其实是最快的路。
2 从 Web 或 Misc 入门 CTF。这两类题对新手最友好，能很快做出第一道，先建立信心比什么都重要。
3 多打靶场、多刷题。本地用 DVWA、SQLi-Labs、Pikachu 练手，在线去攻防世界、BUUCTF、CTFHub、HTB。看不懂题解很正常，照着做一遍，再关掉答案自己复现一遍，就真懂了。
4 打 AWD 前，先补齐「防守」技能。熟悉 Linux、SSH、日志分析、流量分析和基础加固，提前和队友分好工——AWD 一个人可打不了。
5 守住法律与伦理底线。只在授权环境、竞赛靶场和合法 SRC 平台练手，绝不碰未授权的真实目标。这是入门第一课，也是底线。

05说点实在的THE TRUTH
前面讲的都是「能得到什么」，现在也想真诚地聊聊「需要付出什么」。我们不希望你带着误解加入，也希望你能在这里真正学有所成。
我们的承诺
  • 不辜负每一份热爱。只要你有兴趣、肯努力，我们一定会提供足够的资源、指导和展示平台。
  • 期待志同道合的伙伴。我们希望找到真正想学技术、愿意投入时间的人，一起走得更远。
  • 机会留给有准备的人。学分、比赛名额、推荐机会，都会向那些付出努力、坚持不懈的同学倾斜。
需要付出的努力
  • 技术学习需要沉淀。你可能需要牺牲一部分娱乐和社交时间，把精力放在练习和思考上。
  • 但有舍才有得。今天少打一局游戏、少刷一会儿短视频，换来的是伴随你职业生涯的真本事。
  • 网络安全是兴趣驱动的领域。兴趣决定你能否启程，坚持决定你能走多远。
已有基础？ 如果你此前接触过网络安全、打过 CTF 比赛，欢迎直接联系学长，申请提前进行面试和笔试，通过即可进入预备队，快人一步。
没有兴趣，很难熬过初期的枯燥；没有坚持，无法抵达最终的高峰。
但兴趣可以培养，能力可以锻炼，我们愿意陪你一起成长。

我们不做「一上来就面试刷人」那种事。流程分两步：先用一个学期一起学，再决定要不要正式加入。 选择权一直在你手里。
第一阶段

  • 不面试、不筛选，报名就能来，所有同学一起学
  • 学基础：Linux、计算机网络、Python、Web 入门

第二阶段

考核纳新
